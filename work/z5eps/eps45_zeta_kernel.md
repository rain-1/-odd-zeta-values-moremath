# eps45 — the ζ-kernel identities: one PROVED, one VERIFIED

**Context.** eps44 (`eps44.py`, `eps44_kernel.log`) found that the ζ family's
design matrix has a 15-dimensional kernel (rank 125 of 140, both primes),
contradicting the earlier campaign's "rank = columns for ζ" diagnostic. The
kernel is generated by two *per-(n,k)* inner-sum annihilation laws. With
S(n,k,l) = C(n,k)² C(n,l) C(k,l) C(k+l,n) (the ζ summand; support
n−k ≤ l ≤ k):

> **Identity 1** (weight 1): Σ_l S(n,k,l) · (H¹_k − 2H¹_l + H¹_{n−l}) = 0
> **Identity 2** (weight 2): Σ_l S(n,k,l) · [(H¹_k−H¹_l)² − (H¹_{n−l}−H¹_l)² + H²_k − H²_{n−l}] = 0

for every pair of integers 0 ≤ k ≤ n. These two generate 12 of the 15 kernel
dimensions of the weight-3 fit (R × all nine weight-2 monomials over
{n,k,n−k}; G × the three weight-1 letters); the remaining 3 are longer
combinations, all exact-verified (`eps44_kernel.log`).

## Identity 1 — **[PROVED]** (all n, k)

Proof: Zeilberger order-2 telescoping in k. `eps45_verify1.py`
(log `eps45_verify1.log`, ALL PASS, 24s) verifies every step symbolically in
sympy — no numerics in the proof obligations; exact-rational re-verifications
are included as sanity only.

Write W1 = H¹_k − 2H¹_l + H¹_{n−l}, F(n,k,l) = S(n,k,l)·W1, and

    a1(n,k) = −(5k² + 2kn + 16k + 3n + 13)/(n−k)²
    a2(n,k) = (k+2)²(2k−n+3)(2k−n+4)/((n−k)²(n−k−1)²)
    X(l)    = −(k+2)(3k² + 4kl − 4kn + 7k + l² + 5l − 6n + 4)
    d(l)    = l²(k+l+2−n)·X(l) / [(k+1)(k+2)(k+1−l)(k+2−l)(k+l+1−n)(k+l+2−n)]
    u(l)    = −l(k+l+1)(6k³ + 3k²l − 8k²n + 26k² − kl² + 4kln + 14kl − 28kn
              + 36k − 2l² + 6ln + 14l − 24n + 16)
              / [(k+1)²(k+2)(k−l+1)(k−l+2)(k+l−n+1)]

**Certificate** (rational-function identities, sympy-cancelled to 0):
with r(l) = S(l+1)/S(l) = (n−l)(k−l)(k+l+1)/((l+1)²(k+l+1−n)) and
ρ_j(l) = S(n,k+j,l)/S(n,k,l):

    (C1)  r·d(l+1) − d(l) = 1 + a1·ρ1 + a2·ρ2
    (C2)  r·u(l+1) − u(l) = a1·ρ1/(k+1) + a2·ρ2·(1/(k+1) + 1/(k+2))
                             + r·d(l+1)·(2/(l+1) + 1/(n−l))

(C1) matches the harmonic-letter blocks (H¹_k, H¹_l, H¹_{n−l} coefficients,
which are (1, −2, 1)·(C1)), and (C2) the constant spill-over from the letter
shifts H¹_{l+1} = H¹_l + 1/(l+1), H¹_{n−l−1} = H¹_{n−l} − 1/(n−l) and from
H¹_{k+j} = H¹_k + Σ 1/(k+i). Together they give, with
G(l) := S(n,k,l)·(u(l) + d(l)·W1(n,k,l)):

    (*)  G(l+1) − G(l) = F(n,k,l) + a1·F(n,k+1,l) + a2·F(n,k+2,l).

**Boundary audit** (each item verified symbolically in the script):
- S·d and S·u are pole-free at every integer l: their denominators cancel
  exactly into shifted binomials via
  C(k,l)/((k+1−l)(k+2−l)) = C(k+2,l)/((k+1)(k+2)),
  C(k+l,n)/((k+l+1−n)(k+l+2−n)) = C(k+l+2,n)/((k+l+1)(k+l+2)),
  C(k+l,n)/(k+l+1−n) = C(k+l+1,n)/(k+l+1),
  leaving only the never-vanishing (k+1),(k+2),(k+l+1),(k+l+2).
- G(0) = 0: both numerators carry an explicit factor l.
- G(k+3) = 0: both pole-free forms carry the factor C(k+2,l).
- Hence summing (*) over l = 0..k+2 (all three supports contained; both sides
  are values of the same meromorphic-in-l functions at integers, poles absent):

    (R)  P(n,k) + a1·P(n,k+1) + a2·P(n,k+2) = 0   for 0 ≤ k ≤ n−2,
         P(n,k) := Σ_l S(n,k,l)·W1(n,k,l).

  (Also exact-verified over Q for all 231 pairs n ≤ 22.)
- **Base cases** (symbolic, in m): P = 0 for k < n/2 (empty support); for
  n = 2m: k = m is a single cell where W1 ≡ 0, and k = m+1 (3 cells) sums to 0;
  for n = 2m+1: k = m+1 (2 cells) and k = m+2 (4 cells) sum to 0. All four are
  rational identities in m (the H¹ letters differ by explicit rationals).
- **Induction**: for integer k ≥ n/2, a2 has numerator
  (k+2)²(2k−n+3)(2k−n+4) with 2k−n+3 ≥ 3 > 0, so a2 ≠ 0 on the entire
  induction range; upward induction from the base cases gives P(n,k) = 0 for
  all k. ∎

Notes: (i) the certificate was found by parameterized Gosper with the correct
normal form (an earlier attempt with the D-ratio inverted produced garbage —
and sympy's `solve` will happily return *unchecked pseudo-solutions* of
overdetermined linear systems; every solve in the final pipeline re-verifies
residuals). (ii) Order 1 in k and order 1 in n are impossible (residual-checked
exhaustion to numerator degree 7-8): order 2 is minimal. (iii) Gosper fails on
S itself (checked numerically), so no pure Δ_l certificate exists; the
k-recurrence is necessary.

## Identity 2 — **[VERIFIED n ≤ 25, all k; exact Q]** — certificate not found

The same pipeline was pushed hard and failed to produce a certificate:
- pure Δ_l Gosper: excluded (S not Gosper-summable);
- Zeilberger order 2 in k: letter blocks solvable (they reuse d, a1, a2 —
  the h²_k-block equation is identical to identity 1's), but the three
  weight-1 blocks have **no rational solution** (generous denominator
  ansatz, numerator degree ≤ 15, three numeric (n,k) probes);
- joint certificate solve (all blocks + unknown a_j simultaneously, common
  generous denominator, numerator degree 14): **no solution at orders 2, 3, 4**;
- expanded letter alphabet (adding H^{(1,2)} at k+l and k+l−n): no solution
  at orders 2–3 (numeric joint solve).

Status: identity 2 is conjecture-grade (exact-Q, every (n,k) with n ≤ 25) with
an honest obstruction record: if it has a WZ-style proof, it needs either
order ≥ 4-5 in k with a wider denominator/letter space, a mixed Δ_l/Δ_k
certificate, or a different route (e.g. differentiating a proved deformation
of identity 1). Its truth is not in doubt; its certificate is open.

## Why it matters
These are the first proved structural facts about ζ's harmonic letters: the
inner l-sum annihilates the weight-1 combination H¹_k − 2H¹_l + H¹_{n−l}
*pointwise in (n,k)*. Consequences: (a) the eps44 full-degree fit space for ζ
is degenerate — H¹_l and H¹_{n−l} collapse onto H¹_k under the inner sum, so
any future ansatz (Gorodetsky letters, rational coefficients) should be built
on the quotient alphabet; (b) the order-2 recurrence (R) with its cleanly
factored a2 is exactly the kind of object the sporadics paper's template
consumes; (c) the identity-1 proof is elementary and self-contained — two
rational-function identities plus four base cases — and is Lean-formalizable
in the style of the companion certificates.
