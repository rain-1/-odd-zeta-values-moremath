## 1. Results

Let

```text
A_3(n) = sum_{k=0}^n C(n,k)^3,
A_4(n) = sum_{k=0}^n C(n,k)^4,
delta(n,k) = H_k - H_{n-k}.
```

The file proves, for every `n >= 0`, the following closed forms for the canonical second
solutions normalized by `B(0)=0`, `B(1)=1`:

```text
B_3(n) = sum_k C(n,k)^3
  * [ (H_k^(2) + H_{n-k}^(2))/8 + 3 delta(n,k)^2/8 ],

B_4(n) = sum_k C(n,k)^4
  * [ (H_k^(2) + H_{n-k}^(2))/10 + 2 delta(n,k)^2/5 ].
```

Here `B_3` satisfies

```text
(n+1)^2 B_3(n+1) = (7n^2+7n+2) B_3(n) + 8n^2 B_3(n-1),
```

and `B_4` satisfies

```text
(n+1)^3 B_4(n+1)
  = (2n+1)(6n^2+6n+2) B_4(n) + n(64n^2-4) B_4(n-1).
```

The new synthesis with the repo's p-adic line is:

```text
p^2 B_3(ap+r) == B_3(a) A_3(r)  (mod p),  p odd, a,r < p,
p^2 B_4(ap+r) == B_4(a) A_4(r)  (mod p),  p prime, p does not divide 10, a,r < p.
```

The Franel congruence existed previously only for the asymmetric explicit sum `bFranel`.
Theorems `bFranelSym_eq_bFranel` and `bFranel_eq_franelB` now prove that this is exactly the
canonical recurrence solution. The s10 congruence (`bS10Sym_lucas`, `s10B_lucas`) is a new
Lean instance of the abstract theorem `theorem_LB`.

## 2. Proof architecture

For each row, the recurrence applied cellwise to `C(n,k)^d` is first written as a finite
difference `G(n,k+1)-G(n,k)` using an explicit Zeilberger certificate. Applying the same
operator to the harmonic weight introduces only the two-dimensional module generated by
`1` and `delta(n,k)`. Two explicit Gosper cofactors combine into a single antidifference
`Psi`. Lean proves the generic rational identity after denominator clearing, checks the two
top boundary cells separately, and telescopes over `k`. Initial values then identify the sum
with the recurrence-defined solution.

For the Lucas laws, the symmetric weights are expanded into homogeneous weight-two monomials
in four tame letters (`H_k`, `H_{n-k}`, and their order-two analogues). The existing abstract
`theorem_LB` supplies the digit descent. No finite computation is used as a proof step.

## 3. Literature boundary

The harmonic weights themselves are not claimed as new. They are the normalized `t^2`
coefficients of Straub--Zudilin's deformation `A^(s)(n,t)` in *Sums of powers of binomials,
their Apéry limits, and Franel's suspicions*, IMRN 2023, no. 11, 9861--9879
([arXiv:2112.09576](https://arxiv.org/abs/2112.09576)). Their Theorem 1.3 proves that the
coefficient sequences solve every telescoping recurrence in the stated range and determines
their Apéry limits. The present contribution is the explicit all-boundary certificate proof
inside Lean and the recurrence-level p-adic Lucas synthesis.
