2. DESCENT FOR TWISTED TRUNCATED ZETA VALUES                   [ZetaLucas/Letters.lean]

  K_descent (LEMMA K)  For chi : N -> Z completely multiplicative and r >= 1,
                       p^r * K_chi^(r)(y) = chi(p) * K_chi^(r)(floor(y/p))  (mod p),
                       where K_chi^(r)(y) = sum_{m<=y} chi(m)/m^r.
                       This is the mechanism that produces the character factor.
  mon_descent          the same for a monomial in several such letters: the p-power is
                       the total degree and the character value is the product.

3. THE ABSTRACT SECOND-SOLUTION THEOREM                      [ZetaLucas/TheoremLB.lean]

  theorem_LB           Let S : N^2 -> Z, J finite, c : J -> Q, mon : J -> List Letter,
                       w in N, chi_p in Z. Under seven explicit hypotheses
                       (H1) digit factorisation of S mod p,
                       (H2) S(n,k) = 0 for k > n,
                       (H3) digit compatibility of every letter argument,
                       (H4) tameness: every letter argument <= n for k <= n,
                       (H4c) every coefficient c_j is p-integral,
                       (Hw) every monomial has total degree w,
                       (H5) every monomial has character value chi_p at p,
                       one has, for a, r < p,
                            p^w * B(ap+r) = chi_p * B(a) * A(r)   (mod p),
                       where A(n) = sum_k S(n,k) and B(n) = sum_k S(n,k) w(n,k).
                       chi is carried as a hypothesis-bearing function; Mathlib's
                       DirichletCharacter is not used.

6. THE DEFECT MODULE                                             [ZetaLucas/Defect.lean]

  apery_defect_V_eq_zero
                       sum_{k<=n} C(n,k)^2 C(n+k,k)^2 (H_{n+k} + H_{n-k} - 2 H_k) = 0,
                       for all n >= 0.
                       Proof is purely rational — no contour integration, no growth
                       estimate: g = phi^2 with phi(z) = prod_{i=1..n}(z+i)/prod_{j=0..n}(z-j),
                       whose simple poles have residues (-1)^k C(n,k) C(n+k,k) by Lagrange
                       interpolation; Res_m(phi^2) = 2 beta_m sum_{k/=m} beta_k/(m-k) is
                       antisymmetric and sums to zero.
                       (Supporting: Vsum_eq_zero, star_identity, key_poly.)
  wolstenholme_weak    H_{p-1} = 0 (mod p) for p > 2, by the l <-> p-l pairing.
                       Recorded gap: Mathlib contains NO Wolstenholme congruence in any
                       form; this had to be proved from scratch.
  borrow_left / borrow_right / borrow_congr
                       outside the region r+s < p both sides of the digit expansion are
                       = 0 (mod p^2), because A is a SQUARE. (The squareness step is
                       load-bearing for the first-order law.)
  V_restricted_dvd, U_restricted_cong, U_pInt
                       the restricted-to-unrestricted comparison, and p-integrality of
                       U_r for r < p. This is the lemma that was MISSING from the paper
                       draft and from the working notes: the digit expansion holds only
                       on r+s < p, so summing it gives restricted functionals; and U_r
                       genuinely carries p in its denominator (U_5 = 13276637/10,
                       U_7 = 67890874657/70), so its p-integrality is a consequence of
                       r < p and of this lemma, not of anything stated earlier.
